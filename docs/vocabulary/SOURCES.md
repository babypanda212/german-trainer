# Vocabulary sources and decisions

Downloaded 2026-09-23 at Ayesha’s request.

- B2-Aspekte-neu-Kapitelwortschatz.pdf: https://www.klett-sprachen.de/download/7059/aspekte-neu-b2-lb-kapitelwortschatz.pdf
- C1-Aspekte-neu-Wortliste.pdf: https://www.klett-sprachen.de/download/10201/aspekte-neu-c1-lb-wortliste.pdf

B2 and C1 are original publisher PDFs. Text extraction confirmed their expected vocabulary content. They represent textbook vocabulary, not exhaustive Goethe exam lists.

- C2-RadicalRampage-wordlist.txt: https://radicalrampage.com/german/cefr/cefr-c2-vocabulary-practice (pages 1–9).

No equivalent freely downloadable established-publisher C2 list was located. Selected this independent supplementary list to provide actual vocabulary rather than substitute exercises. Its C2 classifications are unverified, not Goethe-approved, and not exhaustive. Extracted all 409 numbered entries in original order with original English translations; checked numbering 1–409. Only HTML markup and layout whitespace were removed. The saved HTML is the original first page only; use the TXT for the complete list.
